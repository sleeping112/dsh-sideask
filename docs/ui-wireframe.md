# 旁问 · UI 线框与交互流程

> 目标尺寸：默认 380×520（最小 300×320，最大 70vw×80vh）；圆角 14px；`--dsw-*` 主题变量 + 兜底色；亮/暗自动适配。
> 所有视觉都活在 Shadow Root 内（`.sa-*` 前缀），失败时自动降级为 light DOM。

---

## 1. 入口：悬浮球（关闭态）

```
┌───────────┐
│ ●  旁问 3 │   ← 圆角胶囊，默认右上角：距顶 40px（`pillOffset` 可调）、距右 18px
└───────────┘
```
- `●` 是状态点：静默灰 / 流式中脉动 / 错误红。
- `3` 是历史线程数（0 时不显示）。
- 点击 = 打开；`Alt+Shift+A` 等效。
- **位置跟随停靠角**：默认由配置 `defaultCorner` 决定（出厂 `top-right`）；窗口被拖动/吸附到哪个角，收起后的球就在哪个角。球本身不单独记忆位置（几何记忆属于窗口）。
- 四角锚定：`top-left` → 左上 18px；`top-right` → 右上 18px；`bottom-left` → 左下 18px；`bottom-right` → 右下 18px。

### 状态变体

**线程菜单**（点标题栏「线」）：列出全部旁问线程，可新建/切换/删除当前

```
┌──────────────────────────────────────────────┐
│ ● 旁问 │ 对话 dbf580c4 │ 线 详 ▴ – ×        │
│              ┌─────────────────────────────┐ │
│              │ 旁问线程                  4 │ │
│              │ ┌─────────────────────────┐ │ │
│              │ │ 错误去重验证            │ │ │ ← 当前线程高亮
│              │ │ 2 条 · 刚刚             │ │ │
│              │ ├─────────────────────────┤ │ │
│              │ │ 真鼠标路径测试          │ │ │
│              │ │ 2 条 · 3 分钟前         │ │ │
│              │ └─────────────────────────┘ │ │
│              │ [＋ 新建] [删除当前]        │ │
│              └─────────────────────────────┘ │
└──────────────────────────────────────────────┘
```
- 点击线程 = 切换并加载其消息；`＋ 新建` = 建空线程并切换；`删除当前` 不可撤销。
- 这些都是插件自己的存储操作，**不影响主对话**。
- 「清空全部历史」仍保留在「详」（上下文详情）面板里。
- **草稿按线程保存**：切换线程各自恢复草稿；`＋ 新建` 的线程草稿为空；发送/删除线程会清掉对应草稿。

### 提问前的上下文编辑

```
输入区上方：
[模型：跟随主对话] [模板]

「详」面板里（将发送的上下文）：
☑ c1 选中 我选中的一段文字…        ← 取消勾选 = 本条不发送
☑ c2 我   最近一条主对话消息…
[恢复全部（1 条已排除）]
```
- 上下文优先级：选中 > 最近窗口 > 摘要。
- 排除只影响本次请求，不改变主对话；下一条问题恢复默认。
- 「模型」选择只影响旁问，默认「跟随主对话」。钉住（pin）功能已移除。

### 重新生成

最后一条回答下方会多出 `重新生成`：先删掉该轮及之后的消息（宿主截断），
再用同一问题重问。非最后一条不出现在按钮里（避免误删后续对话）。

### 分叉与交给主对话（迭代 3）

```
回答下方动作区：
[重新生成] [分叉] [交给主对话] [复制] [引用到主对话] [引用并附注] [作为草稿]
- 分叉：复制「到这条回答为止」的线程前缀为新线程（标题加 · 分叉），并切换过去；
        原线程不变。
- 交给主对话：确认后把 `请执行以下旁问结论：…` 写入主对话输入框（不自动发送）。
- 复制/引用/草稿：和以前一样，显式写回。
```

### 历史摘要（迭代 3）

```
「详」面板：
历史摘要   128 token            ← 来自后台对"窗口外消息"的压缩
退化提示   历史摘要正在后台生成，本轮先用最近消息   ← 第一条超出窗口的问题
```
- 触发：主对话轮次结束（accepted）后自动压缩窗口外消息，按消息 id 集合缓存；
- 失效：窗口外消息集合变化即重新生成；缓存 LRU 8 条；
- 失败：静默忽略，不影响本轮提问。
- **持久化（迭代 4）**：按会话写入 `localStorage['dsh-sideask.summary.v1']`
  （3 会话 × 8 条 × 4000 字上限），刷新页面后自动恢复，不会重复压缩同一段历史。

### 快捷模板（迭代 4）

```
输入区上方：[模型：跟随主对话] [模板]
或在空输入框里直接输入 `/`
┌─────────────────────────────┐
│ 快捷模板            写入输入框 │
│ 解释这段  适合选中一段…        │

│ 总结要点 / 下一步 / 矛盾检查   │

```
- 点击 = 追加到当前草稿（不发送、不覆盖已输入内容）；
- 有选中文本时，"解释这段/找风险"排在最前。

### 面板互斥（迭代 4）

「详 / 线 / 模型 / 模板」同一时刻只开一个，避免浮层重叠。

### 悬浮球拖动（v0.6）

```
关闭态 / 最小化：
┌────────┐
│ ● 旁问 │  ← 按住拖动 = 移动到任意位置（自动限制在视口内）
└────────┘     单击 = 打开窗口
              右键 = 复位到停靠角落
```
- 拖动位置随窗口几何一起持久化（`localStorage['dsh-sideask.window.v2']`，schema 3）；
- 拖拽阈值 4px：轻点不会被误判为拖动；
- 拖动后不会自动打开窗口（click 被吞掉一次）；
- 视口缩小时自由位置自动夹紧，不会跑到屏幕外。

```

- `degradableToQuestionOnly=true` → 显示“仅用问题回答”（不读上下文重问）。

## 3. 交互流程

### 3.1 主流程（快捷键 → 回答 → 回写）

```
[Alt+Shift+A] 或 点悬浮球
      │
      ▼
 窗口打开（恢复上次位置/尺寸/折叠态；首次用 defaultCorner）
      │
      ├─ 探针已上报当前会话 → 标题栏显示「对话 xxxx」
      │
      ▼
 输入问题 → [Enter]
      │
      ├─「带上上下文」开 → extracting（异步、可取消、1.5s 超时降级）
      │        └─ 只读 eventSource 快照 → 去重 → 预算 → 脱敏 → c1..cN
      │
      ▼
 POST /plugins/dsh-sideask/api/ask（SSE）
      │  accepted → settings → delta(流式) → usage → done{text, citations}
      │
      ▼
 渲染：流式文本 + 引用 chip；[复制][插入引用块][引用到主对话][作为草稿]
      │
      ├─ 点「复制」→ navigator.clipboard（失败→隐藏 textarea execCommand）
      ├─ 点「插入引用块」→ insertQuote（false→insertText→setDraft→剪贴板）
      ├─ 点「引用到主对话」→ 同上 + “— 引用自旁问”
      └─ 点「作为草稿」→ setDraft（失败→剪贴板）
      │
      ▼
 主对话状态：**未被自动修改**；只有用户点动作时输入框被写入（不自动发送）
```

### 3.2 选中文本 → 旁问

```
主对话里选中文字
      │
      ▼
插件收到 selection interaction（readText() 取文本；不抢占官方引用插件的弹层）
      │
      ├─ 记录为「本次提问的最高优先级上下文」(c1)
      └─ toast：已捕获选中片段，按 Alt+Shift+A 打开旁问即可提问
      │
      ▼
 打开窗口 → 提问 → 选中片段作为 c1 参与预算（上限 40%）
```

### 3.3 关闭 / 清空 / 会话切换

| 操作 | 发生什么 | 主对话 |
|---|---|---|
| 点 `×` | 窗口关闭（状态保留），胶囊回来 | 不变 |
| `Alt+Shift+A` | 关闭 ↔ 打开切换 | 不变 |
| 清空当前线程（删除） | DELETE /threads/:id | 不变 |
| 清空全部历史 | DELETE /threads | 不变 |
| 主对话切换会话 | 探针重新上报 → 线程视图清空并绑定新会话 | 不变 |
| 关闭「带上上下文」 | 下次提问不发送任何对话内容（宿主二次校验） | 不变 |

## 4. 键盘映射

| 键 | 作用域 | 行为 |
|---|---|---|
| `Alt+Shift+A` | 全局（插件自有监听） | 打开/收起旁问；不经过 dsh 快捷键服务（该服务拒收无 primary 的 Web 组合并会抛错），因此不会与宿主快捷键设置联动，也不会因冲突让插件失效 |
| `Esc` | 窗口内 | 收起窗口（保留状态） |
| `Enter` | 输入框 | 发送（输入法组合中不触发） |
| `Shift+Enter` | 输入框 | 换行 |
| `Ctrl/Cmd+Enter` | 输入框 | 发送（与 Enter 等价，便于习惯差异） |
| 双击标题栏 | 标题栏 | 折叠/展开 |
| 拖动标题栏 | 标题栏 | 移动；松手距边 <24px 吸附到该角 |
| 拖动右下角 | 缩放手柄 | 调整尺寸（300×320 ～ 70vw×80vh） |

无障碍：所有按钮都是原生 `<button>` 且有 `title`；输入框有 `placeholder`；引用 chip 的说明通过 `title` 提供；动效受 `prefers-reduced-motion` 抑制。

## 6. 挂载与降级

真实浏览器审计发现：`shell.overlay`（z-index 20）会被主对话的 sticky 输入区盖住，
窗口下半部分（含输入框）无法点击。因此**窗口改为 body 级挂载**，插槽只作空 mounter。

```
shell.overlay 插槽
   └─ Mounter（渲染 null，仅用来拿到生命周期）
        └─ document.body 下创建容器 div
             style: position:fixed; left/top:0; width/height:0; z-index:2147483000
             ├─ attachShadow('open')
             ├─ <style data-sideask="shadow">（本插件全部 CSS）
             └─ createRoot(shadowRoot) → WindowShell
                  ↑ 失败（无 Shadow DOM / createRoot 抛错）
             └─ 回退：light DOM（同一容器，样式表挂到容器内，.sa-* 前缀）
                  ↑ 再失败
             └─ 兜底：console.error 说明原因（窗口不可用，主对话不受影响）

z-index 取舍：body 级 2147483000 一定高于整个 app frame，所以窗口也会盖住
模态框/抽屉。这是"输入框可点"换来的；若要严格低于模态，需要宿主提供更高的
插槽层（当前没有）。
```
```
